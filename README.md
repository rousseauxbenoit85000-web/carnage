# CARNAGE

FPS d'horreur avec des morts-vivants, en un seul fichier HTML (aucune dépendance, aucun build).
Moteur en raycasting sur canvas 2D, sons générés par Web Audio.

## Jouer

Ouvrez `index.html` dans un navigateur, ou publiez le dépôt avec GitHub Pages
(Settings → Pages → Branch `main` / dossier `/ (root)`).

## Niveau 1

Trouvez la clé rouge, puis la clé bleue, pour atteindre la salle du boss : **Le Chirurgien**.
Les portes s'ouvrent en s'en approchant avec la bonne clé.

## Commandes

**Clavier / souris**

| Action | Touche |
|---|---|
| Se déplacer | Z Q S D (ou W A S D) |
| Viser | Souris (ou flèches ← →) |
| Tirer | Clic / Espace |
| Recharger | R |
| Courir | Maj |
| Changer d'arme | 1 / 2 / E |
| Lampe torche | F |
| Pause | Échap / P |

**iPhone / mobile (mode paysage)** : stick à gauche pour bouger, glisser à droite pour viser,
boutons FEU, R, ARME, lampe et pause.
